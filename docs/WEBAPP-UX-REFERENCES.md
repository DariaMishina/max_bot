# Улучшения WebApp по референсам

Реализовано в `max_bot_test`, ветка `feature/max-webapp`.

На скриншотах конкурента сильнее всего работают понятный вход через темы, помощь в формулировке вопроса, отдельный экран ожидания и узнаваемая история диалогов. Эти приёмы адаптированы под сиреневую палитру «Сферы Таро».

## Что добавлено

- Шесть крупных плиток на главной: отношения, работа и карьера, финансы, перемены, мой выбор, о себе. Тема подставляет редактируемый вопрос; схема расклада меняется только явным выбором пользователя.
- Примеры вопросов прямо в форме и кнопка очистки. Свой вопрос открывается с пустым полем.
- Экран ожидания показывает принятый вопрос, прошедшее время и пояснение, где найти готовый ответ. Анимация обозначает ожидание, без выдуманных процентов и этапов генерации.
- История показывает начало сохранённого ответа и кнопку нового расклада. Для активного запроса есть возврат к ожиданию.
- Расклады и уточнения из WebApp остаются в WebApp. Запросы из чата доставляются в чат; три карты объединяются в одно изображение.
- В ответе сохраняются выбранные позиции и общее толкование: 2–3 предложения на карту, 3–4 на итог с советом. Все позиции схем выделены заголовками.
- Базовая и подробная консультации имеют отдельные описания состава услуги; цены остаются прежними.

## Границы изменений

Тарифы, пакеты, лимиты и выдача полного ответа работают по прежней схеме. Фото, дата рождения и персональные сгенерированные изображения не добавлялись: для них нужны отдельные функции обработки, хранения и генерации. Счётчики активности без реальной статистики не используются.

## Проверка

Браузерные проверки на ширинах 320, 390 и 768 px: выбор темы и схемы, редактирование и очистка вопроса, ожидание, история и отсутствие горизонтальной прокрутки. Серверные проверки работают на отдельной локальной БД; MAX API подменяется в тестах доставки.
